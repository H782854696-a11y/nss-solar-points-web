## 保留原则

- 继续使用现有接口、数据库字段、权限检查和审批操作。
- 首页指标只读现有权限范围的数据，不增加全局数据暴露。
- 未开发项目在页面计划中标记为未完成，不用静态样例冒充实时系统功能。
