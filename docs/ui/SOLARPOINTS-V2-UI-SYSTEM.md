# SolarPoints V2 全系统 UI 设计规范

版本：0.1（总管理员首页阶段）  
状态：基于用户确认的 A+C 方案及首页参考图整理；首页是后续页面的视觉基准。

登录页另按用户确认的 B 方案（NSS Solar 品牌视觉）独立设计；登录后管理区继续使用 A+C，不互相覆盖。

## 设计原则

- 采用现代企业管理界面与高效工作台的融合方式。重点信息在首屏可见，常用动作一步进入。
- 以 NSS Solar 品牌资产为准，不重绘或替换现有标识。
- 工作区使用白卡片和浅灰底色，左侧导航使用深海军蓝；危险、提醒、成功颜色只表达状态。
- 中文与英文共用同一布局，文案经现有 `t()` / `ccText()` 本地化，不用图片中的固定中文替代国际化。
- 首页指标来自现有受权限控制的接口；没有数据来源的指标明确标记为待建设，不造数。
- 响应式布局按桌面、平板、手机连续适配；手机优先堆叠信息与保留可点按目标。

## 字体与排版

- 字体沿用系统栈：Inter、Noto Sans SC、PingFang SC、Microsoft YaHei、系统无衬线字体。
- 页面标题 22–24px / 600–700；卡片标题 15–16px / 600；正文 13–14px；辅助信息 11–12px。
- 数字使用等宽数字特性，方便比较统计数值；长标题截断并保留完整信息的可访问文本。
- 采用 8px 间距基准，卡片内部 16–20px，主要区块间距 16–24px。

## 共用组件

- **导航**：深色固定侧栏，分组清楚；当前项高亮；窄屏使用抽屉及遮罩。
- **页头**：明确标题、简短用途说明、日期或范围信息；全局搜索和用户操作放在顶栏。
- **统计卡**：标签、主要数字、简短趋势/状态；整卡可点时使用按钮语义并提供键盘焦点。
- **筛选与表单**：标签清晰、必填提示一致、输入错误贴近字段；操作按钮顺序和尺寸一致。
- **表格与列表**：桌面表格、手机卡片；状态标签、分页、空态及加载/错误状态统一。
- **审批与任务状态**：状态颜色固定且同时显示文字，不只靠颜色传递信息；逾期需明确显示。
- **附件、弹窗与确认**：沿用现有上传区、模态框、危险操作二次确认模式。
- **进度与历史**：进度条必须带文本或数值；重要操作历史保留人员和时间。

## 首页信息层级

1. 欢迎语、日期和当前角色。
2. 五类工作指标：待审批、未完成任务、门店整改、未读通知以及 7 天内预计到货；后续仅在存在可靠数据源时增加异常指标。
3. 今日待办和最近事项，提供直接进入对应业务页的操作。
4. 工作分布与门店运行概览，严格以现有接口数据为来源。
5. 快捷操作。

参考效果图中显示的订单优惠统计、按门店完成率、新店拓展进度等，只有在后端已提供可靠数据后才能作为实时指标展示；目前应列入后续功能，而不是由静态视觉内容伪装成已完成。

## 屏幕适配

- 桌面（>1200px）：保留多栏工作台和完整侧栏。
- 平板（641–1200px）：内容卡片改为两栏或单栏，避免过窄列。
- 手机（≤640px）：抽屉导航；指标双列或单列；任务列表纵向排列；按钮至少保持舒适的触控高度。
- 支持横向溢出控制、系统安全区和减少动态效果设置。

## 现有令牌位置

- 色彩与暗色主题：`public/tokens.css`
- 通用组件及断点：`public/styles.css`
- 已确认的中控平台细化样式：`public/ui-review.css`
- 页面本地化：`public/i18n.js`

## 登录页 B 方案（独立视觉范围）

- 背景采用明亮的企业建筑与太阳能板品牌摄影，白色/浅蓝为底，绿色用于品牌与登录主操作。
- 桌面为左侧品牌介绍、右侧白色登录卡；平板和手机改为纵向排布，保留语言切换。
- 使用现有 NSS Solar 品牌资产；登录账号、密码、可见性切换、提交按钮及认证逻辑保持原样。
- 样式限定在 `#loginPage` / `.login-page`，不得把浅色品牌登录主题套用到已登录的业务工作台。
