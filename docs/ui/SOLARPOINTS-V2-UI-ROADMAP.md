# SolarPoints V2 UI 分阶段开发计划

所有阶段在独立开发分支与隔离环境完成。每阶段提供电脑与手机运行截图供用户确认后，再进入下一阶段。生产部署需另行明确授权。

| 阶段 | 范围 | 验收重点 |
| --- | --- | --- |
| 1. 盘点与规范 | 现有页面、组件、令牌、权限和接口盘点；形成 UI 规范、页面对照和计划 | 明确已实现/部分实现/未开发，保留功能清单。 |
| 2. UI 基准页 | 按独立 B 方案完成 NSS Solar 登录页；按 A+C 完成总管理员首页 | 登录认证保持原样；首页真实接口数据、权限过滤、中英切换；桌面/手机截图；无横向溢出。 |
| 3. 组织、账号与审批 | 组织树、人员职位、账号权限和审批中心 | 复用现有工作区与 RBAC；操作、筛选、状态、手机适配。 |
| 4. 任务、协作与业务流程 | 任务协作、优惠、采购、报销、收货、到货跟踪及通知 | 保持审批路径与接口行为；补齐流程状态和附件反馈。 |
| 5. 门店运营与分析 | 门店管理、巡检、整改、新店拓展和统计报表 | 新店拓展等未有数据模型的功能先做需求及数据设计，再做 UI；统计不展示无来源数据。 |
| 6. 全面适配与收尾 | 桌面、平板、手机统一复核；键盘、可读性、加载/错误/空态和回归检查 | 提交真实运行截图、测试记录、已知限制和变更清单。 |

## 当前执行

阶段 1、2 已完成首轮并经用户确认；阶段 3 首轮现已在独立分支实现组织/部门/职位/人员与区域/门店树、账号入口归组核对，以及按组织树选择具体审批人员。组织及审批设置沿用现有接口、RBAC 和数据格式。首页沿用现有中控平台数据接口和权限控制；登录页 B 方案仅作用于认证前页面。销售额、门店百分比进度、新店开业进度等尚无对应可用数据时不展示为真实指标。
